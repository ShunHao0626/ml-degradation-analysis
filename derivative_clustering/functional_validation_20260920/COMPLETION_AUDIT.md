# 本轮请求的逐项验收

本轮范围：阅读原 SOM 与后续导数论文，判断导数方法是否有助于用户四种目标形态；
以 EG 风格的模拟曲线先测试模型代码。用户明确说明新版真实数据尚在整合，
真实数据检出率不是此时可验证的事实，也不作为虚假完成项。

| 原始要求 | 当前证据 | 判定 |
|---|---|---|
| 考察 SOM 原文借鉴是否适用于目标 | 读取并渲染 SOM 第 4–5 页、SI 第 16–17 页；REPORT 明确区分论文四类与 IFO 四类及预处理条件 | 完成 |
| 考察导数聚类论文能否融入 | 核对论文 HP、多项式、导数与 DTW 公式；实现论文式对照、直接导数 SOM、D1 图、共享路径/分距离融合 | 完成；正负结果均报告 |
| 保持附件定义的 Bridge/Hill/Slope/Valley | 已查看附件；协议与生成代码记录四类阶段结构；检查独立生成组实际观测图 | 完成；仅形态定义，不声称机制拟合 |
| 基于 EG 风格人工整合用于测试 | 原有 400 条 + 新种子三批 + 独立函数三批；另有稀疏、截断、背景混合测试，观测与参数均保存 | 完成；不是 EG 像素数字化 |
| 主要验证模型代码功能 | 16 项测试通过，编译 DTW 与原实现对照；无标签 CLI 已跑完 400 条，五种图划分与主实验一致 | 完成 |
| 判断是否能找出四类并解释失败原因 | summary/metrics/assignments、214 行 ARI 复算、背景精确率与簇数诊断；报告导数 SOM 负结果、目标与自然簇差别、稀疏和截断限制 | 完成；不承诺所有真实数据都可分 |
| 可复用与可复现 | README、PROTOCOL、代码、manifest 哈希、原始模拟观测、单独标签、验证脚本和完整结果 | 完成 |

输出检查文件为 `outputs/verification.json`。源 400 个 CSV 哈希全部未变。
最终图已目视检查，修复了混合组簇标题过密问题。

未宣称完成的后续研究：真实数据盲审、目标类别自动命名与置信度、经过真实样本
标定的非目标拒识、更多 SOM 表征/优化器和物理动力学分支。这些不等于本轮已经
验证的模拟功能，也不应使用合成标签匹配准确率替代。
